## 決定

json-render を採用せず、React で判断用 UI を実装する方針に仕様を変更する。説明・比較・選択肢・推奨理由・回答送信を維持する。画面構成の JSON 生成、catalog、ui.spec、json-render 用の UI API を必須契約から外す。DEC-0004 の CLI 配布方針は維持する。

## 出典

2026-11-09（JST）の Codex チャット 01a1bc27-227d-7ba2-a8e8-c3866492c3da。エージェントが「今回のprepare-devには、json-renderは不要です。採用しない方を勧めます」と回答した後、人は「じゃあいったんいいや」、続けて「止めますじゃなくて仕様変えないとだめだろ」と指示した。Q-0026 はこの既存指示の転記であり、新たな承認依頼ではない。DES-0002 はその指示の具体化であり、人が文書全文を審査したことを示すものではない。

## 反映

具体化案、README、UI の README を更新し、実装が旧方式のまま残ることを明示する。過去の引き継ぎ原文と検証記録は書き換えない。実装の変更と検証は別作業として残す。
