## 判断（人の回答）

Q-0028 で「なくす」を選んだ（補足なし）。

## 読み取ったこと

- prepare-dev は MCP の入口（`prepare-dev mcp`）を提供しない。エージェントは skill に従って CLI を使う。
- このリポジトリの `.mcp.json` と `.codex/config.toml` にある prepare-dev の登録も消す。
- DEC-0004 の「MCP 登録を前提にしない」から進めて、入口そのものを持たない。

## 棄却した案

- 残す: CLI を実行できず MCP しか使えない環境から使う予定がない。CLI と同じ操作の重複で、今の流れでは使っていない。

## 影響

- REQ-0010 の「MCP 登録を作成しない」を「MCP の入口を提供しない」に改める。
- DES-0002 のうち MCP に触れた箇所を直す。skills の本文から MCP の記述を除き、操作名と CLI のコマンドの対応を示す。
