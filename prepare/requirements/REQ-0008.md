## 現行要求への置き換え（2026-11-09）

DEC-0004と、UI・CLI配布まで実装・検証する指示に基づき、この旧案の要求を置き換えた。現行の要求はREQ-0010、設計はDES-0003、受入仕様はSPEC-0004。本記録の残りは変更前の案と検討理由を保存する履歴であり、現行実装への追加要件にはしない。

checkoutなしでCLI・UI・検証接続を使う意図はREQ-0010/P1・P4へ引き継ぐ。配布tarballとOrigin検査は実装・検証済み。npm公開は今回の対象外。

## 要求

段階 2 を選んだ場合: 道具リポジトリの checkout と `node_modules` が無い機械で、配布物（束ねた JS と同梱の UI）だけで入口・デーモン・UI 配信・検証プラグインが動く。配布物はビルド済みの release 成果物として置き、利用者の機械ではビルドしない。置き場所と取得方法は設計で決める。

前提条件: デーモンの HTTP の origin 制限の要求（別件。作成時に本記録の `links.depends_on` に id を書く）が `accepted` であること。それまで本要求は `accepted` にしない。

本件は記録（`prepare/` 配下）の形式を変えない。形式を変える変更は別件で、配布物の版との互換はそこで扱う。

`coverage.self` は、この要求を今回の範囲に入れるか（`could` のまま）外すか（`wont`）が Q-0003 の判断（作成予定）であることを示す。用語は DIS-0001 の「用語」に従う。

## 根拠

- 段階 2 の価値は「道具リポジトリと `node_modules` が要らなくなり、他者が試せる」こと（DIS-0001 §価値）。段階 1 の要求（REQ-0002〜0007）だけでは checkout に依存し続ける。
- 当面の利用者は所有者本人という仮説（H5）が偽なら必要になる。真なら今回は `wont`。
- esbuild は依存木にあるが、MCP SDK の ESM 束ねと UI の同梱は未試行（H6）。
- デーモンは無認証で `access-control-allow-origin: *` なので、他者の機械で動かす前に origin 制限が要る（DIS-0001 §リスク 段階 2）。

## シナリオ

- 通常: Given 道具リポジトリも `node_modules` も無い機械、When 配布物を PATH に置いて対象リポジトリで `init` と `status` を実行する、Then 動く。
- 通常: Given 配布物だけの機械、When ブラウザで `/` を開く、Then 同梱の UI が表示される。
- 通常: Given 配布物だけの機械、When `verify run --plugin vitest` を実行する、Then 対象リポジトリ側の vitest で検証が動く。
- 例外: Given Node の版が要件（>= 26）を満たさない、When 入口を起動する、Then 分かるエラーで止まる。
- 例外: Given origin 制限の要求がまだ `accepted` でない、When 本要求を `accepted` にしようとする、Then 前提条件を満たしていないので `accepted` にしない。
- 例外（中断と再試行）: Given 配布物の置き換え中にデーモンが動いていた、When 新しい入口が接続する、Then REQ-0004 の照合で不一致を検出し、失敗するか再起動する。

## 受入条件

- AC-1: `node_modules` と checkout を消した環境で `prepare-dev status` が動く。
- AC-2: 同じ環境で `GET /` が本来の UI を返す。
- AC-3: 同じ環境で vitest プラグインと lean4 プラグインが対象側の道具で動く。
- AC-4: 入口の起動（MCP の initialize 応答まで）が目標値以内（目標値は Q-0003 で決める。上限は Codex の `startup_timeout_sec = 30` 秒）。配布物の大きさと起動時間を計測して DIS-0001 の H6 の証拠欄に記録する。
- AC-5: Node の版が足りないとき、分かるエラーで止まる。
- AC-6: 前提条件の要求が `accepted` になっている。

## 対象外

- npm レジストリへの公開と版管理（DIS-0001 非目標）。F は妨げないが本要求には含めない。
- origin 制限の実装そのもの（別件の要求）。
- Windows（DIS-0001 非目標）。
