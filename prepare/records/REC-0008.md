0.3.0-dev の配布物（darwin-arm64）を作って別の場所で動かし、判断画面をブラウザで操作して確かめた記録。確かめた build は frontmatter の checked のとおりで、88a8095 に REV-0071〜0074 の指摘への対応（まだコミットしていない変更）を足したソースから作った。主張の証拠は RUN で、この記録は RUN の代わりにはならない。確認はエージェント（Claude Code）が行った。変更のある作業コピーから作ったので、後から同じ build は作れない。

`go run ./scripts/release -version 0.3.0-dev -out <scratchpad>/dist -targets darwin/arm64` で配布物を作った。

リリースのスクリプトは、置き場を移した配布物の README の元（scripts/release/distribution-readme.md）を README.md として同梱した。同梱の README には、更新の手順（`prepare-dev init` の実行し直し）がある。`prepare-dev version` は `0.3.0-dev` を返した。

展開した実行ファイルを `PREPARE_DEV_E2E_BINARY` に渡して `go test ./internal/e2e -count=1` を動かし、次のすべてが通った。

- TestGuidance: [P2] prepare-verify の skill の guidance に、各プラグインの名前と版が書いてある（このテストは checkout に埋め込んだ skills を読み、配布物の実行ファイルは使わない。のちに testP2Skills に移した）
- TestDistribution: [P1] 質問・回答・判断・trace の流れ（Node.js、Go、checkout なし）、[P1] 実際の lake での Lean の検証と trace、[P2] init による skills のコピー（status が、編集された skill、古い版が入れた skill、無い skill を示し、init の後は示さないことを含む）、[P3] 書き手が一つであること（停止、再起動、強制終了したデーモンの置き換え、別の build の拒否、lease を失ったデーモンの停止）、[P3] TypeScript 版の daemon.json を引き継がないこと、[P3] 二つの作業コピーからマージした prepare/ を拒むこと、[P3] Git がジャーナルを置き換えたデーモンが書かずに止まること、[A1] CLI に回答の操作が無く、API は判断画面からの回答だけを受け付けること
- TestCrashRecovery: [C3] 段階 question の後の強制終了で取り消し、段階 commit の後の強制終了で確定

## 判断画面（ブラウザ）

展開した実行ファイルで一時的なプロジェクトを作り（`init --no-skills`）、要求を一つと質問を五つ作って、Claude Code のアプリ内のブラウザで判断画面（127.0.0.1）を操作した。

| 質問 | 操作 | 画面の表示 | 記録された回答 |
| - | - | - | - |
| 単一選択 | 推奨の「受け付けない」を選んで送信 | 「回答済み」「回答を保存しました。エージェントが続きの作業を進めます。」、回答の中身と「エージェント処理待ち」 | choice reject、stale false |
| 複数選択 | 「メール」と「アプリの通知」を選んで送信 | 回答済み、「メール、アプリの通知」 | choice mail・push |
| 自由記述 | 文を書いて送信 | 回答済み、「自由記述」と書いた文 | 文だけ（choice なし） |
| stale | 質問の後に対象の要求を書き換え（status が subjects changed since asked を示した）、「はい」で送信 | 送信中に「保存しています…」。その後「資料が更新されています。回答は保存されますが、自動では判断に反映されません。エージェントによる再確認が必要です。」と、回答に「対象が更新済み」 | choice ok、stale true |
| 失敗 | 画面を開いた後にデーモンを止め、「はい」で送信 | 「回答を保存できませんでした。Failed to fetch 入力は残っています。接続を確認して再送してください。」 | 記録されず、質問は回答待ちのまま |

送信中の表示（「保存しています…」）は stale の確認でだけ写った。ほかの送信は短く、読んだときには完了していた。

## 確かめていないこと

- Linux（arm64・amd64）と darwin-amd64 では動かしていない。今回の変更（設定の検査、status での skills の比較、guidance の置き場、trace の判定の使い回し）は OS に依らない。Linux のコンテナでの確認は、85477c7 としてコミットする前の作業コピーから作った build のもの（REC-0007 の checked）。
- TypeScript 版との共存は確かめ直していない。デーモンの識別と lease は変えていない（e2e の [P3] は通った）。
- 判断画面のソースは 85477c7 から変えていない（ui/build はそのまま）。
- 送信中の表示を、すべての種類の質問では確かめていない。
- REV-0071〜0074 の再確認の後にコードを直したら、その build はこの記録の build と違う。
