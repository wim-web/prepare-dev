## UI の切断・再接続

使い捨てのローカルプロジェクトを Chrome で開き、回答が「エージェント処理待ち」であることを確認した。`apply.commit` の保存後、最終通知前にデーモンを強制終了。画面は未接続になった。同じ保存先・ポートで再起動すると、ページ再読込や質問の選び直しなしに「反映済み → DEC-0001」へ戻り、未処理回答一覧から消えた。

この経路を修正するため、SSE の接続・再接続時に選択中の質問も再取得するようにした。取得開始時と現在の選択 ID を照合し、別の質問を上書きしない。検証用プロセスと一時ディレクトリは後片付け済み。

## 検証中に追加で修正した採番

未完了ジョブの artifact ディレクトリが採番時に数えられず、二つのジョブが RUN-0006 を使った。ディレクトリを ID の予約として数えるよう修正し、完了前・再起動後の非再利用を SPEC-0003/V2 とテストに追加した。

RUN-0006 は履歴として残すが、今回の完了証拠には使用しない。修正後の RUN-0007 と RUN-0008 は異なる ID・保存先で実行し、両方の結果と適用可能性を確認した。

## 保証の範囲と当時残っていた移行

Lean の証明はモデルについての保証。TypeScript 実装との対応は、実行した trace とテストの範囲の保証であり、実装全体の形式証明とは扱わない。静的 import から分からない fixture・実行時に組み立てるパス・生成元は `impl_files` に明示する。外部パッケージは manifest と lockfile に従って導入されていることを前提とする。

この検証時点の対象は上の6件と関連不具合。その時点で残っていたCLI梱包とReact UIへの移行は、その後に完了した。[配布検証記録](REC-0006.md)と[M2の完了確認](REC-0003.md)を現在の状態として参照する。
